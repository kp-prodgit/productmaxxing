A state, as a dot and a word. The word carries the meaning; the colour lets the eye find it again.

**Use** one pill per object, for its state now. Tones: `.ok` done or delivered, `.now` the person's move, `.warn` needs attention soon, `.bad` failed, `.held` held back or waiting at a gate, none for neutral, `.draft` for a draft nobody sees yet (hollow dot). `.plain` drops the dot for a count or a label that is not a state.

**You provide** one or two words in sentence case.

- Do keep the same word for the same state everywhere: "Released", "Waiting on you", "Draft".
- Don't show a pill for the normal case when every row would carry the same one. Mark the exception.
- Don't use a bare coloured dot. A dot without a word fails the greyscale test.
- Don't invent a tone. If none fits, the state is neutral.
