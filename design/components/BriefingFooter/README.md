The last thing on a briefing page: who owns it and how to reach them, which edition it is, the confidentiality line again, and what the marks mean.

**Use** `.b-foot` once, at the end of every briefing page, after the last passage. It closes the page on paper as well as on screen.

**You provide** in `.own` the owner by name and role, then each way to reach them as `.sel` plain text (an address, a channel), so it can be selected and copied with one click; in `.ed` the edition in `b` with the date and the audience, and the same confidentiality `.pill.held.plain` the cover shows; and `.chg` "Parts marked New or Updated changed since edition 1." when the page has marks.

- Do repeat the confidentiality line exactly as the cover says it. A printed last page travels alone.
- Do name a person, not a team inbox alone.
- Don't turn contact details into buttons; a reader on a shared screen needs to read them.
- Omit `.chg` on a first edition or when nothing is marked.

States: restricted page, page for everyone (no confidentiality pill), first edition (no `.chg`).
